# Auto Reconnect Roblox

Script em AutoHotkey v2 que mantém você no jogo do Roblox (8 idiomas): reabre se fechar ou desconectar, posiciona a janela, manda status no Discord (com print e moedas) e se atualiza sozinho.

## Como usar
1. Instale o [AutoHotkey v2](https://www.autohotkey.com/).
2. Baixe o arquivo **`roblox_autorejoin.ahk`** (clique nele aqui em cima → botão de download).
3. Dê dois cliques no arquivo, cole o link do jogo/servidor na aba **Jogo** e clique em **Iniciar**.

## Atualizações
O script avisa sozinho quando sai versão nova (aba **Sobre**). É só clicar em **Atualizar**.
As novidades de cada versão ficam no [CHANGELOG.md](CHANGELOG.md).
